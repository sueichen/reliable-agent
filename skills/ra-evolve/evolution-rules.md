# 进化规则

> 此文件定义 ra-evolve 何时和如何生成进化建议的补充规则。

## 触发阈值

| 条件 | 行动 |
|------|------|
| 同类错误 >= 2 次 | 生成 Type A 建议（CLAUDE.md 规则） |
| 同一审查发现 >= 2 次 | 生成 Type A 建议（CLAUDE.md 规则） |
| 同一流程摩擦 >= 2 次 | 写入技能专属经验，生成 Type A 建议（流程约束） |
| 安全发现（任何次数） | 生成 Type A 建议（安全基线更新） |
| process-win（任何次数） | 记录但通常不需要变更（正向强化） |
| 经验总数 >= 10 | 提示用户运行 ra-evolve |

## 大小限制

| 文件 | 硬上限 | 水位线 | 超水位动作 |
|------|--------|--------|-----------|
| CLAUDE.md | 500 行 | — | 拒绝新增规则，只允许精简替换已有规则 |
| `.reliable-agent/experiences.md`（集中式） | 800 行 | 600 行 | 凝练合并已有条目 |
| `.reliable-agent/<skill>/experiences.md`（技能专属） | 800 行 | 600 行 | 凝练合并已有条目 |

## 精简三原则

所有经验写入和进化建议必须遵守：

1. **非必要不增加**: 已有条目覆盖的，不新增；缺乏会导致重复踩坑的，才新增
2. **增加必精简**: 每条经验 ≤15 行；每条建议 ≤20 行；能一句话说的不用一段
3. **非必要不重复**: 写入前扫描已有条目，相同根因+相同上下文 → 更新已有条目，不新增

## 建议格式

每条建议必须包含:

```markdown
### [TYPE-X]: [简短标题]

- **触发经验**: [EXP-YYYY-MM-DD-NNN 引用]
- **当前行为**: [当前 CLAUDE.md/spec 怎么说或怎么做]
- **建议变更**: [确切的新文字或流程]
- **理由**: [为什么此变更防止重复]
- **影响范围**: [哪些技能/流程受影响]
- **风险**: [如果应用了可能出什么问题]
- **替代方案**: [考虑过但未采用的其他方法]
```

## 禁止的变更

以下变更即使在经验中出现了，也不应生成建议：

1. **移除安全控制**: 任何削弱安全基线的变更
2. **降低测试标准**: 任何降低覆盖率阈值或移除测试要求的变更
3. **跳过门禁**: 任何允许跳过质量门禁的变更
4. **删除经验**: 删除 `.reliable-agent/experiences.md` 或 `.reliable-agent/<skill>/experiences.md` 中已有的经验记录
5. **削弱人类审查**: 任何减少人类审查检查点的变更
6. **修改技能文件**: 任何对 SKILL.md 中流程定义（DOT 图、步骤序列、HARD-GATE 规则）的直接修改。以下不在此限：
   - 修复拼写错误、格式问题、死链接
   - 更新 frontmatter 版本号
   - 经人类审批的安全约束添加——走 Type A 建议流程在 CLAUDE.md 中新增规则

## 进化频率

- 建议: 每 3-5 条新经验后运行一次
- 最多: 每周一次（避免变更疲劳）
- 最少: 每 sprint 一次（如果积累了大量经验）
