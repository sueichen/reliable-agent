# Markdown 代码规范（简洁版）

> 基于 Google Markdown Style Guide 整理的核心规则速查。

---

## 文件命名

| 规则 | 格式 | 示例 |
|------|------|------|
| 扩展名 | `.md` | `my-document.md` |
| 命名 | `lowercase-with-dashes` | `api-reference.md` |

## 段落与格式

| 规则 | 要求 |
|------|------|
| 段落分隔 | **空行**分隔 |
| 行宽 | 不超过 **80 字符**（链接/代码块除外） |
| 强制换行 | 不要在段落内使用 |
| 行尾空白 | ❌ **禁止** |

## 标题

- 文件仅有一个 `#`（H1）作为文档标题
- `#` 后留一个空格
- 层级不跳跃（不要从 H2 跳到 H4）
- 标题前后有空行
- 使用句子式大小写

```markdown
# 文档标题

## 一级子标题

### 二级子标题
```

## 列表

| 类型 | 标记 | 示例 |
|------|------|------|
| **无序列表** | `*`（星号） | `* 第一项` |
| **有序列表** | `1.` | `1. 第一步` |
| 缩进 | 2 空格 | `  * 嵌套项` |

## 代码

| 类型 | 语法 |
|------|------|
| **行内代码** | `` `code` `` |
| **代码块** | 围栏式 + 指定语言 |

```markdown
使用 `git status` 查看状态。

```python
def hello():
    print("Hello")
```
```

## 链接与图片

| 类型 | 格式 |
|------|------|
| **行内链接** | `[text](url)` |
| **引用式链接** | `[text][ref]` + `[ref]: url` |
| **图片** | `![alt](url)` |
| 协议 | 尽可能使用 **HTTPS** |

## 格式速查

| 格式 | 语法 |
|------|------|
| 加粗 | `**bold**` |
| 斜体 | `*italic*` |
| 行内代码 | `` `code` `` |
| 水平线 | `---` |
| 删除线 | `~~text~~` |
| 引用 | `> text` |

## 表格

```markdown
| 左对齐 | 居中对齐 | 右对齐 |
|:-------|:--------:|-------:|
| 内容 1 | 内容 2   | 内容 3 |
```

## 标注

```markdown
> **注意：** 重要注意事项。
> **提示：** 有用的提示。
> **警告：** 警告信息。
```

## 目录

```markdown
## 目录

1. [简介](#简介)
2. [安装](#安装)
3. [使用](#使用)
```
