# 三层进化模型

## 模型概览

项目在三个层级上持续改进，每个层级有不同的自动化和审批要求。

```
┌─────────────────────────────────────────────┐
│  第一层：Experience（经验文件）               │
│  角色：自动追加，AI 可读写                    │
│  文件：.reliable-agent/experiences.md        │
│  内容：错误模式、优化发现、审查高频问题         │
│  进化方式：/ra-evolve Phase 1 自动追加             │
│  风险：低（只记录，不改变行为）               │
├─────────────────────────────────────────────┤
│  第二层：Configuration（项目配置）            │
│  角色：AI 可提议，人类审批后生效              │
│  文件：CLAUDE.md                             │
│  内容：代码规范细则、commit 模板、边界规则      │
│  进化方式：/ra-evolve 读取经验 → 生成建议 │
│  风险：中（改变行为，但范围受限）               │
├─────────────────────────────────────────────┤
│  第三层：Skills（命令技能）                    │
│  角色：AI 可提议，人类审批后生效               │
│  文件：skills/ra-*/SKILL.md             │
│  内容：工作流步骤、门禁规则、验证标准          │
│  进化方式：/ra-evolve 生成变更建议       │
│  风险：高（改变核心行为，必须人工确认）         │
└─────────────────────────────────────────────┘
```

## 经验文件格式

```markdown
### EXP-[YYYY-MM-DD]-[NNN]: [简短标题]

- **类别**: error-pattern | optimization-discovery | review-recurrence | workflow-friction | security-finding | process-win
- **上下文**: 我们在做什么
- **症状**: 观察到的行为
- **根因**: 为什么会发生
- **解决方案**: 什么修复了它
- **预防**: 如何防止再次发生
- **严重度**: critical | important | notable
- **标签**: 关键词
```

## 进化流程

```
/ra-evolve (每个 session 结束，或周期性)
    │
    ├─ Phase 1: 回顾 session → 提取经验 → 追加到 experiences.md（自动）
    │
    ├─ 积累 >= 3 条新经验 → 自动进入 Phase 2-4
    │
    ├─ Phase 2: 聚类分析经验 → 识别重复模式（>= 2 次）
    │
    ├─ Phase 3: 生成三种建议：
    │   ├─ Type A: CLAUDE.md 规则变更
    │   ├─ Type B: Skill 行为变更
    │   └─ Type C: Spec 修订
    │
    └─ Phase 4: 所有建议等待人类审批
```

## 禁止的进化

以下变更即使经验中出现也不应生成建议：
1. 移除安全控制
2. 降低测试标准
3. 跳过门禁
4. 删除已有经验
5. 削弱人类审查
